## Activation checklist

1. **Vercel:** import [the GitHub repository](https://github.com/musabrashid/budget-app) at [Vercel New Project](https://vercel.com/new), or add `VERCEL_TOKEN` to the managed environment's secret settings for CLI deployment.
2. **Supabase:** open [your project](https://supabase.com/dashboard), create your private email/password Auth user, disable public signup, and configure the Site URL. Put the project URL/publishable key and the server-only `SUPABASE_SECRET_KEY` in the appropriate app environment.
3. **Plaid:** add `PLAID_CLIENT_ID` and the **Sandbox** `PLAID_SECRET` privately. Use `PLAID_ENV=sandbox`. Generate and store a stable `PLAID_TOKEN_ENCRYPTION_KEY` with `openssl rand -base64 32`; keep it out of Git and chat.
4. **URLs:** set `NEXT_PUBLIC_APP_URL` to the deployment's exact HTTPS origin and `PLAID_WEBHOOK_URL` to that origin plus `/api/plaid/webhook`; redeploy.
5. **Verify live flow:** sign in → connect Sandbox bank → refresh → review categories → save a custom category/transaction edit/budget → close/reopen → refresh twice → verify no duplicate spending and successful signed webhook delivery.
6. **iPhone:** open HTTPS in Safari → Share → Add to Home Screen → launch Still.

Exact commands, variables, setup screens, security decisions, limitations, and troubleshooting are in [README.md](README.md). Rollover computation, recurring detection, FX conversion, shared budgets, alerts, savings goals, and password-recovery UI are not implemented. Do not treat this as a certified real-bank production launch until the external flow has been tested with valid operator credentials.
